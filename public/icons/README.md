
# Munal Favicon Assets

This directory contains the source SVG assets for the Munal application.

## Assets
- `icon-192x192.svg`: Scalable vector icon used for PWA manifest (replaces 192px PNG)
- `icon-512x512.svg`: Scalable vector icon used for PWA manifest (replaces 512px PNG)
- `apple-touch-icon.svg`: Apple touch icon source

## Usage
The application is configured to use modern SVG favicons which are supported by all modern browsers. 

If legacy support (IE11, old Safari) is strictly required, please convert these SVG files to PNG/ICO formats using an online converter or image editing tool and replace the file extensions in `index.html` and `manifest.json`.

## Colors
- Primary Purple: #7C3AED
- Secondary Purple: #9333EA
- Text/Icon: #FFFFFF
